# Customer Feedback Intelligence System

## Overview
An NLP-based system for analyzing customer feedback, identifying sentiment
and recurring discussion topics, and tracking changes in feedback patterns.

## Features
- VADER sentiment analysis
- BERTopic topic discovery
- Monthly sentiment and topic trends
- Cosine-similarity-based topic drift detection
- SKU-level complaint analysis
- Streamlit dashboard

## Tech Stack
Python, VADER, BERTopic, Streamlit

## How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
